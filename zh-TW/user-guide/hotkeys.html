熱鍵 ​

下面所有全域與應用程式內熱鍵都可以在設定 → 熱鍵裡重新綁定；這裡列出的是預設值。設定介面本身見 設定 → 熱鍵頁面。

搜尋框圖示 ​

搜尋框裡那個小圖示(具體在左側還是右側,取決於視窗)在三種視窗裡各自 有不同的作用：

  • 快速視窗 —— 左鍵點擊(不移動)會彈出和系統匣圖示右鍵一樣的選單(顯示主視窗、切換熱鍵、設 定、關於、乾淨結束、結束)，選單出現在游標位置；選單裡的「顯示主視窗」還會帶上你目前輸入框裡的 搜尋內容。按住左鍵拖曳會移動視窗，和拖曳搜尋列其它部分一樣——拖曳時(不管是拖搜尋列還是拖圖 示)按住 Ctrl 可以把移動方向限制成只能縱向，拖到一半按下/放開 Ctrl 也能即時生效，適合只想 上下調整位置而不想帶偏橫向位置的時候用。右鍵點擊會把視窗重設回預設螢幕位置(不影響大小)——和 首次啟動時的置中位置相同。滑鼠停留時的提示會把這三種手勢都列出來。

    記住的位置是相對於上次所在顯示器的相對位置，不是絕對螢幕座標——換到另一台顯示器(或者解析度、 DPI 縮放不同的顯示器)上叫出時，會在那塊螢幕上按比例換算到對應位置，而不會跑出螢幕外或落到錯誤 的顯示器上。

  • 內嵌視窗 —— 只有當視窗停靠在原生的開啟/儲存/瀏覽資料夾對話方塊上時才可點擊：左鍵點擊會觸發 快速導覽，效果和下面專門的觸發方式一樣。當停靠在一般檔案總管視窗或桌面上 時不可點擊，因為那種情況下沒有什麼可供跳轉的目標——這時既不會有滑鼠停留高亮，也不會有提示。

  • 主視窗 —— 這個圖示在主視窗裡純粹是裝飾性的，點擊沒有任何效果。

快速導覽(滑鼠) ​

預設啟用，每種觸發方式都可單獨在設定裡開關：

  • 在桌面或檔案總管視窗的空白處按兩下左鍵觸發快速導覽。
  • 在桌面或檔案總管視窗的空白處、受支援的第三方檔案管理員(Directory Opus、Total Commander、 XYplorer、Files 等)的檔案清單區域、或原生的開啟/儲存/瀏覽資料夾對話方塊裡點擊中鍵觸發快速 導覽。這些其它視窗只回應中鍵——按兩下在那裡已經是「開啟這一項」的意思，所以沒有把按兩下挪作他 用。參見支援的檔案管理員了解每種整合具體涵蓋哪些能力。
  • 當內嵌搜尋視窗停靠在原生的開啟/儲存/瀏覽資料夾對話方塊上時，它自己的圖示同樣可以觸發快速導覽 ——見上面的搜尋框圖示。

無論哪種方式觸發，都會彈出一個串接式選單，內容是你的我的最愛、歷史記錄和設定好的捷徑資料夾(見 設定 → 我的最愛和設定 → 歷史記錄)——外掛也可以往裡 新增自己的項目，比如你在 wincmd.ini 裡設定過 Total Commander 的 Directory Hotlist 的話，它也會 出現在這裡，或者是某條勾選了「在快速導覽中顯示」的自訂命令(可以 透過 / 分隔的路徑把它歸到某個子選單下)。每個貢獻項目的外掛在選單根層級都有自己獨立的標題分組， 這些分組的先後順序可以自己調整——見 設定 → 通用 → 快速導覽。點擊資料夾會讓目標視窗跳轉過去；點擊檔案也 會跳轉過去，並在其所在資料夾中選取該檔案，而不是開啟它——唯一的例外是桌面，那裡沒有可供跳轉的現 有視窗面板，所以在桌面上點擊資料夾或檔案會直接開啟它，效果和按兩下一樣。如果是在檔案選擇器裡，點 擊檔案則是讓對話方塊跳轉到該檔案所在的資料夾——絕不會替你自動確認「開啟」/「儲存」。

這個選單實際上是由串接式資料夾瀏覽器外掛建構的。除了可以各自獨立開關的我的最愛和歷史記錄，它 還有自己的一份可設定捷徑資料夾清單——在設定 → 外掛 → 串接式資料夾瀏覽器 → 設定裡新增路徑和可 選的顯示名稱，再給它填一個 Submenu 值(比如 工具/網路，用 / 分隔可以巢狀多層)，就能把它歸到某 個分類下而不是直接顯示在根層級。選單的每一層——根層級和任意巢狀分類——的標題上都有一個小小的 + 按鈕：點它可以把你目前瀏覽到的資料夾直接加進來，名稱、路徑和這一層自己的子選單路徑都會預先 填好(新增前仍可編輯)，不用離開選單去設定裡操作。

硬編碼按鍵(不可設定) ​

無論熱鍵設定如何，以下按鍵始終保持相同行為：

按鍵情境行為
Escape任意情境若搜尋框有內容則清空;否則關閉視窗(或退出動作選單)。
Enter結果清單開啟選取結果。
Ctrl+Enter結果清單在檔案總管中定位該結果，而不是開啟它。
Ctrl+Shift+Enter結果清單以系統管理員身分開啟該結果。
左/右方向鍵動作選單返回上一層選單 / 進入子選單。
Backspace動作選單當搜尋框已為空時，退出動作選單。
Alt+Space / Alt+F4快速視窗、主視窗、設定視窗、QuickLook 預覽面板、外掛設定視窗，以及 SwiftList 自己的訊息彈出視窗這幾個視窗上都會被封鎖——不會彈出 Windows 的系統選單，Alt+F4 也不會關閉視窗。

外掛動作熱鍵 ​

外掛可以註冊自己的動作並附帶一個預設熱鍵(例如複製路徑 Ctrl+Shift+C、以系統管理員身分執行，或是 內建的檔案操作動作——剪下 Ctrl+X、複製 Ctrl+C、貼上 Ctrl+V、刪除 Delete、徹底刪除 Shift+Delete)。這些會顯示在設定 → 熱鍵 → 外掛動作 裡，按註冊它們的外掛分組，重新綁定方式 和內建熱鍵相同。

處理程序黑名單 ​

如果 SwiftList 的全域熱鍵和某個應用程式(比如會獨佔鍵盤原始輸入的遊戲)衝突，把該處理程序加入處 理程序黑名單即可——詳見設定 → 熱鍵頁面。當黑名單裡 的處理程序處於前景時，SwiftList 的全域熱鍵、按鍵攔截，以及上面的快速導覽滑鼠觸發都會被完全放行， 不會攔截。

任何真正全螢幕的前景應用程式都會自動取得同樣的效果，不需要手動加入黑名單。無論哪種情況，目前作用 中視窗如果是檔案選擇器，都會被豁免，快速導覽依然可以正常使用。
