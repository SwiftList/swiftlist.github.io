설치하기 ​

홈페이지의 다운로드 버튼에서 최신 릴리스를 받으세요 — 릴리스마다 두 가지 형태로 제공됩니다.

  • 설치 프로그램 (SwiftList-Setup.exe) — 권장 방식입니다. 백그라운드 인덱싱 서비스를 등록하며 Windows와 함께 SwiftList를 시작하도록 설정할 수 있습니다.
  • 포터블 (SwiftList-Portable.zip) — 압축을 풀고 실행하기만 하면 되며, 설치 과정이 없습니다. 백그라운드 서비스는 나중에 설정 → 서비스 상태에서도 설치할 수 있습니다. 사용 중인 컴퓨터에 SwiftList가 필요로 하는 .NET Desktop Runtime이 아직 없다면, 함께 제공되는 install-dotnet-runtime.bat를 한 번 실행하세요 — 설치 프로그램은 이 단계를 자동으로 처리하지만, 포터블 빌드는 그럴 수 없습니다. 포터블 설치를 다 사용한 뒤에는 정리해 줄 제거 프로그램이 없습니다. 폴더를 삭제하기 전에 함께 제공되는 portable-cleanup-registry.reg를 더블클릭(프롬프트 확인)하여 SwiftList가 스스로 만든 두 개의 사용자별 레지스트리 항목 — swiftlist:// URI 프로토콜 등록과 "Windows와 함께 시작" 항목 — 을 제거하세요. 둘 다 사용자별(HKCU) 항목이므로 관리자 프롬프트는 필요하지 않습니다.

두 형태 모두 x64 빌드와 ARM64 빌드로 제공됩니다. 위의 이름은 x64 빌드이며, 최근의 PC라면 어디서든 실행됩니다 — Windows on ARM에서도 에뮬레이션으로 실행됩니다. ARM 기기에서는 네이티브로 동작하는 SwiftList-Setup_arm64.exe 또는 SwiftList-Portable_arm64.zip을 사용하세요. 자동 업데이트는 설치할 때의 아키텍처를 그대로 유지하므로, 다른 쪽으로 옮기려면 직접 내려받아야 합니다.

처음 실행하면, SwiftList는 파일 인덱싱을 담당하는 Windows 서비스(SwiftList.Service)를 설치하고 시작합니다. 이렇게 분리한 것은 의도적인 설계입니다 — 그 이유가 궁금하다면 아키텍처를 참고하세요 — 하지만 사용자로서 알아야 할 것은 하나뿐입니다. 설정 → 서비스 상태에서 서비스가 설치되어 실행 중인지 알려주며, 설치되어 있지 않다면 그곳에서 설치할 수 있습니다.

세 가지 창 ​

SwiftList에는 검색 창이 하나만 있는 것이 아닙니다 — 사용 방식에 맞게 적응합니다.

  • 메인 창 — 작업 표시줄/시작 메뉴 바로가기에서 얻는 전체 창으로, 가장 큰 결과 목록과 창 내 Actions 패널을 갖고 있습니다.
  • 퀵 창 — 전역 토글 단축키(기본값은 Ctrl 두 번 누르기)로 불러오는, 항상 위에 떠 있는 소형 팝업입니다. "단축키 누르기 → 입력 → Enter"라는 근육 기억을 위해 만들어졌습니다.
  • 인라인 창 — 지원되는 네이티브 파일 대화상자나 파일 탐색기 창 안에 SwiftList 검색창을 직접 내장하여, 이미 열려 있는 대화상자를 벗어나지 않고도 검색할 수 있게 합니다.

세 창 모두 동일한 검색 엔진, 단축키 시스템, Actions 메뉴를 공유합니다 — 차이는 순전히 어디에, 어떻게 나타나는지에 있습니다.

기본 검색 ​

최근 파일, 즐겨찾기, 기록은 아무것도 입력하지 않고도 꺼내 쓸 수 있습니다 — 모두 빠른 패널의 탭이며, 이 패널은 검색 창 안이 아니라 앞에 있는 창 위에 열립니다.

그냥 입력을 시작하세요. 입력하는 대로 결과가 관련성 순으로 갱신됩니다(매칭과 순위가 어떻게 동작하는지는 검색 문법 참고). 설정 가능한 다음/이전 항목 단축키(기본값은 화살표 키)로 선택을 이동하고, Enter로 강조된 결과를 여세요.

다음 단계: 쿼리 상자를 최대한 활용하려면 검색 문법을 확인하세요.
