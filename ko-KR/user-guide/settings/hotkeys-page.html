단축키 (설정 페이지) ​

세 개의 탭: 전역, 플러그인 동작, 프로세스 차단 목록입니다. 각 단축키가 실제로 무엇을 하는지는 단축키 페이지를 참고하세요 — 이 페이지는 설정 UI 자체를 문서화합니다.

전역 ​

전역 단축키 그룹:

  • 퀵 검색 표시/숨기기 — 레코더 컨트롤. 단일 수정자 키(두 번 누르기 모드, 기본값 Ctrl) 또는 전체 조합을 받아들입니다. 그 옆의 전체 화면 앱이 포커스를 가진 동안에도 계속 응답 — 체크박스, 기본값 꺼짐 — 은 이 단축키(그리고 빠른 전환, 인라인 검색 활성화)를 아래의 프로세스 차단 목록에서 설명하는 자동 전체 화면 예외 대상에서 제외합니다.
  • 빠른 전환 — 기본값 Ctrl+G.

기능 키 그룹:

  • 다음 항목(Ctrl+N), 이전 항목(Ctrl+P), 결과로 이동 수정자(기본값 Ctrl, 숫자 1~9와 짝을 이룸), 동작 메뉴 열기(Ctrl+O), 선택 항목으로 완성(Ctrl+Tab), QuickLook(Alt+P), 이전/다음 키워드 기록(Alt+Up / Alt+Down), 키워드 기록 항목 삭제(Ctrl+Delete), 전체 창 열기(기본값 Ctrl+F — 현재 쿼리를 그대로 유지한 채 전체 창을 바로 엽니다. 퀵 창 자체의 로고를 좌클릭하고 메인 창 표시를 선택하는 것과 같은 효과지만, 그 추가 클릭이 없습니다).
  • 여기의 모든 레코더는 여러분이 누르는 어떤 키나 조합이든(단순한 Tab 같은 키 포함) 받아들이며, 그 바인딩은 그 키가 원래 가지고 있을 수 있는 어떤 하드코딩된 기본 의미보다 우선합니다.

빠른 탐색 그룹:

  • 빈 공간 더블 좌클릭 — 체크박스, 기본값 켜짐.
  • 빈 공간 미들클릭 — 체크박스, 기본값 켜짐.

시작 패널 그룹:

  • 다음 시작 패널 탭(Ctrl+Right), 이전 시작 패널 탭(Ctrl+Left) — 시작 패널의 탭 스트립을 순환(끝에서 다시 처음으로)합니다. 해당 패널이 실제로 표시되고 있을 때만 활성화됩니다.

플러그인 동작 ​

플러그인이 등록한 동작(예: 경로 복사, 관리자 권한으로 실행)마다 하나의 항목이 있으며, 플러그인 이름별로 그룹화되어 각각 자체 단축키 레코더를 가집니다. 변경하기 전까지는 플러그인 자체가 제안하는 기본값을 그대로 사용합니다.

프로세스 차단 목록 ​

포그라운드 포커스가 SwiftList의 전역 단축키, 키 입력 가로채기, 빠른 탐색 더블클릭/미들클릭 마우스 트리거를 완전히 억제해야 하는 실행 파일 이름(예: game.exe)을 추가하세요. 대소문자를 구분하지 않으며, .exe 접미사는 선택 사항입니다. 인덱스 아래의 제외 규칙과 동일한 하나씩 추가/일괄 편집 패턴을 지원합니다: 단일 항목 텍스트 상자와 프로세스 추가, 기존 항목 목록, 그리고 텍스트 생성 / 텍스트 적용이 있는 일괄 텍스트 상자입니다.

이는 전체 화면 게임이나 원시 키보드 입력을 가로채는 다른 앱과의 단축키 충돌에 대한 해결책입니다 — 자세한 내용은 문제 해결을 참고하세요. 진짜로 전체 화면인 포그라운드 앱은 어떤 것이든 여기에 항목을 추가하지 않아도 자동으로 동일하게 처리됩니다 — 단, (전역 아래, 퀵 검색 표시/숨기기 옆의) 전체 화면 앱이 포커스를 가진 동안에도 계속 응답이 켜져 있다면 그 예외에서 완전히 제외됩니다. 어느 경우든 활성화된 파일 대화상자는 항상 예외이므로, 그곳에서는 빠른 탐색이 계속 동작합니다.
