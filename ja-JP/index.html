外観

SwiftListWindows 向けの高性能で拡張可能な検索ツール

数百万件のローカルファイルを数秒でインデックス化。軽量かつ高速で、強力なエイリアスとプラグインのエコシステムを備えています。

💾ダウンロード
はじめるプラグイン開発
💡

Listary の代替

商用のファイル検索ランチャーに代わる、モダンで美しく、高い拡張性を備えたオープンソースの選択肢です。

🚀

瞬時のインデックス作成

Windows の USN Journal と MFT を活用し、数百万件のファイルを数秒で読み取ります。軽量で、バックグラウンドサービスを通じてシステム全体で共有されます。

🎯

あいまい検索とエイリアス

前方一致/後方一致/完全一致/除外演算子を備えたタイプアヘッドのあいまい検索に加え、中国語ファイル名向けのピンインエイリアスにも対応。詳しくはユーザーマニュアルをご覧ください。

⌨️

完全にカスタマイズ可能なホットキー

ウィンドウの切り替え、次/前のアイテム選択、アクションメニュー、QuickLook プレビューなど、すべてのホットキーを自分のワークフローに合わせて再設定できます。

🔌

拡張可能なプラグイン

オープンな SDK アーキテクチャにより、独自の検索プロバイダー、エイリアス、コンテキストメニューアクション、UI 拡張機能を簡単に作成できます。

🛡️

プロセスの分離

SYSTEM レベルで動作するバックグラウンドのインデックスサービスは、セッションレベルのユーザー App UI とは分離されており、最大限のセキュリティとパフォーマンスを実現します。
