Listary Alternative

A modern, beautiful, and highly extensible open-source alternative to commercial file search launchers.

🚀

Instant Indexing

Leverages the Windows USN Journal and MFT to read millions of files in seconds, lightweight and system-shared via a background service.

🎯

Fuzzy Matching & Aliases

Type-ahead fuzzy matching with prefix/suffix/exact/exclude operators, plus pinyin aliasing for Chinese filenames — see it all in the User Manual.

⌨️

Fully Customizable Hotkeys

Every hotkey — toggle window, next/previous item, actions menu, QuickLook preview — can be rebound to fit your workflow.

🔌

Extensible Plugins

Open SDK architecture allowing easy creation of custom search providers, aliases, context-menu actions, and UI extensions.

🛡️

Process Isolation

A SYSTEM-level background indexing service is kept separate from the session-level user App UI, for maximum security and performance.
